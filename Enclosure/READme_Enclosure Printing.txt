1 - Download Latest Version of Bambu Studio from "https://bambulab.com/en-gb/download/studio"

2 - Click File -> Import and locate "Noise Extrapolator - Full Enclosure Kit[BambuStudio]"

3 - Select desired Filament Colours and materials.

* Note that Original 3mf Project file contains working settings and filaments, User may need to adjust if using a different slicer or printer. The original project was printed using a Bambu Lab P1S 3d printer and Bambu PLA Filaments.

4 - Print Enclosure.

* If Having Issues on 3rd party printer, Remove the Branding and Text Elements which should make the project easier to print on almost any 3d Printer with a 0.4mm Nozzle.

* Decals or Paint can be used to decorate and label the printer enclosure following completion.

5 - Check Build Of Materials (BOM.txt) and populate PCB then Assemble to build the final Device.
