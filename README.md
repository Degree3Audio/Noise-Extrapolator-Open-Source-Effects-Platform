# Noise-Extrapolator-Open-Source-Effects-Platform
A free to use accesible project for DIY Customisable Hardware Effects Pedals using Daisy Seed Rev7

Overview
This repository hosts the Open-Source Asset Pack for the "Degree3audio Noise Extrapolator Effects Pedal Platform". This project provides a practice-led, open-source framework for DIY audio hardware development breakout board and Hardware Pedal Build, targeted at the Electrosmith Daisy Seed platform. The overarching mission is to support the democratisation of music technology and hardware creation by removing financial and technical barriers for independent creators to create Desktop Hardware Effects Devices.

Hardware Features
The fully assembled physical effects device features:
4x Vertical Sliders 

1x Horizontal Mix Slider  

Momentary Digital Switching  

Repository Contents
Hardware: Gerber files and Bill of Materials (BOM) for custom PCB manufacturing.
Enclosure: 3D-printable STL and 3MF files for the pedal housing.
DSP Code: Plugdata patches and JSON configuration files for immediate deployment.
