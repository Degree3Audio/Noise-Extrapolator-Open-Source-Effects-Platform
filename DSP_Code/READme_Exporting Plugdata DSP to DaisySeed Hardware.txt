1 - Download Plugdata [Visit https://Plugdata.org] and execute a full installation (Include all options for full install of included Libraries).

2 - View reference documentation / Download and install the Daisy Seed Libraries [Visit Https://docs.daisy.audio]

2 - Open Plugdata App and click the "Burger" (3 horizontal lines) button in the top left of the window, then select 'Open' and locate 'Noise Extrapolator_HyperDelay_Plugdata Patch.pd' to open the project containing the working patch.

3 - It is MANDATORY to select the 'NoiseExtrapolatorConfig.json' File prior to exporting from Plugdata to the DaisySeed Rev7 hardware.

* The Json File connects the logic in the Plugdata Patch with the Pins on the Daisy Seed Hardware, thus ensuring the correct functionality of the final Pedal Build (e.g. The Physical 'Mix' Slider works with the accompanying Mix Param in the DSP).

* Visit https://plugdata.org and https://docs.daisy.audio for Installation Docs & Further details.
